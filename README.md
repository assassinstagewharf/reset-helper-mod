## 📖 About

Reset Helper streamlines single-player speedrun resets: one key quits to title, starts a new world with your preset seed and settings, and begins the run timer automatically.

---

## ✨ Features
<a name="features"></a>

- **One-Key Reset** — quit + new world + start timer in one keypress.
- **Preset Manager** — save multiple world presets (seed, settings, game mode).
- **Run Timer** — auto-starts IGT on world load.
- **Split Support** — compatible with LiveSplit via WebSocket.
- **Practice Mode** — reload same seed without resetting the category.
- **Statistics** — tracks reset count and average session time.

> 🔑 **100% free** — no key system, no linkvertise, no ads.
